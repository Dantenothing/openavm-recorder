只用车机录像，完成第 1 节即可；只用手机车控，从第 2 节开始；需要传录像，再完成第 3 节。

## 1. 车机：录下第一段视频

1. 停好车，使用车机浏览器打开[项目发布页](https://github.com/Dantenothing/openavm-recorder/releases)，选择 V5 的 `OpenAVM-Recorder-` APK。
2. 从下载记录打开安装包，通过车辆固件提供的 App Lab／安装器完成安装。已有本项目版本时直接覆盖，不先卸载。
3. 打开 **AVM Recorder**，根据提示允许相机、存储访问；使用悬浮后视镜时再允许悬浮显示。安装入口与权限页面随车机固件不同。
4. 停车核对前后左右画面及驾驶位设置。V5 首次升级会设置一次：右侧驾驶位，前 1／后 2／左 3／右 4，车内 Camera 1、红外 Camera 0。不匹配时在设置中调整。
5. 插入可识别、可写的 USB 存储，选择 USB 优先，然后检查页面显示的**实际录像存储位置**。
6. 选择环视、普通模式，点“开始录像”。确认显示录像中，录一小段，再点“停止”并等保存完成。
7. 打开“记录”，找到刚才的视频并播放。

**完成标准：记录中有刚才的视频，而且能回看。** 只有预览画面不代表正在录像；插入 USB 也不代表当前正在写入 USB。

录像、USB 设置与其他普通设置随同签名覆盖升级保留。拔 USB 前先停止并等待保存完成，重要录像另行备份。

### 设置回车后的行为

在“设置 → 回车后的行为”选择：

| 选择 | 回车时怎样使用 |
| --- | --- |
| Logo 入口 | 点 OpenAVM Logo 恢复预览，长按打开菜单 |
| 完整悬浮窗 | 亮屏解锁后恢复预览 |
| 完整悬浮窗＋自动录像 | 额外主动开启“同时自动开始录像”；默认不勾选 |
| 关闭保留入口 | 回车后手动打开应用 |

每次安装或覆盖升级后重新确认选择，保存设置不会立即开始录像。相机刚唤醒时会等待就绪，请看实际画面与录像状态。主动停止后，当次不会反复自动开始。

应用被系统结束或车机重启后，需要重新打开。**这不是离车后持续停车录像，也不是远程唤醒车辆。** 关闭悬浮窗不会停止已经开始的录像；结束录像请使用停止按钮。

### 留下重要片段

普通录像时点击“保存紧急视频”或悬浮窗的紧急按钮。系统标记可用的前两段、当前段和后一段；当前、后一段须完成后才能保存。开始太晚或很快停止时，实际段数可能少于四段。

在“记录 → 紧急事件”检查结果。保护可防止自动清理，不代替备份，也不阻止你明确确认的永久删除。

## 2. 手机：连接车辆与配置日常使用

### 登录车辆

1. 在 Android 手机上安装 V5 的 `OpenAVM-Phone-` APK，已有原 OpenAVM 时直接覆盖安装。
2. 打开 **OpenAVM**，进入“更多 → 账号与连接”。
3. 登录有车辆授权的极氪账号，选择车辆。guest 账号需先获得主账号授权。
4. 刷新一次，核对是否为自己的车辆及车况的数据时间。

**完成标准：选中了正确的车辆，并读到车况。** 5.0.1 候选版不内置连接参数；请先导入自行准备且有权使用的六字段配置，再登录。升级旧版需重新导入一次，录像与车机配对保留，自动化需重新开启。当前车控适配基线是澳洲版 7X / AU 1.6.6，其他地区不能直接按已兼容处理。

登录会话加密留在本机，日常无需反复输入；会话失效、授权变化或换手机时可能需要重新登录。想只看本地录像，可以跳过极氪账号登录。

### 设置家和原厂哨兵规则

1. 进入“更多 → 停车位置与家”，输入部分地址并选择匹配结果，或在家时使用手机当前位置。
2. 核对位置，设置合理的家的范围。这个范围用来容忍车辆定位偏差。
3. 进入“更多 → 停车守护”，按需要分别开启“离家停车自动守护”和“确认到家后自动关闭”。

保存家地址本身不会开启规则。离家开启需要可信、近期的车况、停车及锁车等条件；到家关闭需要至少间隔一分钟的两次新数据确认，不会因为拿到两次相同旧记录就立即关闭。

在 OpenAVM 或卡片中手动关闭哨兵，会暂停本次停车的自动开启；在家中手动开启，会保留本次开启。原厂 App 或车机上的手动操作，需要读到可识别的状态变化，不能保证每次都能识别操作意图。确认新的行驶与停车后再按规则处理。

**完成标准：家位置正确，规则页面显示你实际想开启的规则。** 自动化操作和结果可在“更多 → 操作记录”查看，不需要为了配置而立刻触发一次车控。

### 设好备车偏好

进入“更多 → 智能备车设置”，选择目标温度、最长时长，以及是否允许座椅通风或加热。保存偏好不会启动空调。

在首页或桌面卡片点一次“一键备车”开始，再点进行中的同一按钮停止。查看“发送中／等待车辆／正在预冷或预热”等实际反馈；受理指令不等于车辆已经完成。预约出发在“自动化”中设置。

备车效果受天气、车辆状态和数据新旧影响，不承诺固定时间一定达到目标温度。琥珀／蓝色气流用于提示预热／预冷过程，不是独立的温度传感器。

### 添加桌面卡片

进入“更多 → 桌面卡片”，预览并选择 **2×2、4×1、4×2 或 4×3**，点击添加后，在系统桌面弹窗中确认。

如果没有弹窗或没有新增卡片，长按桌面空白处，进入“小组件”，找到 OpenAVM 后手动拖入。不同手机桌面会影响占格和可调整范围。

卡片中的车锁、哨兵、找车、备车等常用操作可以直接发起；点应用入口打开完整页面。看操作进度及车辆回传，不要把按钮点击动画当成执行成功。

**完成标准：桌面出现卡片，能够打开 OpenAVM，且显示正确车辆的状态与数据时间。**

### 两个刷新按钮分别做什么？

| 按钮 | 实际行为 |
| --- | --- |
| 顶部普通刷新 | 读取云端车况，不启动临时空调 |
| 温度旁刷新 | 单独更新车温；必要时短暂开启空调，随后请求结束本次临时空调 |
| 后台更新 | 查询车况，不自动启动上述取温流程 |

再次点击进行中的取温按钮可结束取温。若空调或备车原本就在运行，不把它当作本次临时空调去关闭。若提示停止尚未确认，请查看后续状态，不把请求发出当成已经关闭。

车辆休眠时，云端可能继续返回同一份温度。“刷新成功”只表示读取成功，**不代表此刻重新测量**。车温更新也需等待车辆回传，不能保证每次马上有新值。

### 配好后台运行

进入“更多 → 后台与自动化”，按页面检查：

- 通知：显示执行进度、失败原因和运行中的任务。
- 电池与后台联网：减少系统限制导致的延迟。
- 闹钟与提醒权限：使用预约出发时按提示设置。
- 附近设备：仅在使用可选车载蓝牙触发时按提示授予。

手机定位用于“把当前位置设为家”等相关操作，不需要为了看录像而授予。不要一次性开启不需要的权限。

**完成标准：所需规则已启用，页面没有对应权限缺失提示。** Android 省电、网络和车辆休眠仍可能延迟执行，不能把设置完成理解为永久实时在线。

## 3. 两端配对：把录像传到手机

这一步与极氪账号登录分开。只传本地录像，不需要云端车辆账号或私人服务器。

1. 两端都使用 V5 配套版本。手机开热点，让车机连接；或让两端接入允许相互通信的同一 Wi-Fi。
2. 手机进入“影像 → 连接车机”（也可从“更多 → 车机连接与配对”进入），开启接收，再开启安全配对窗口。
3. 车机进入“手机与车机工具”页，点“自动查找”，或填写手机页面显示的地址。填入六位配对码，点“核对并配对”。
4. 在弹出的“核对手机身份”窗口中，逐组核对两端显示的**完整指纹**。完全一致再勾选核对框，点“确认并配对”；不一致时取消。
5. 在车机选择一段已保存的录像发送。等待手机接收完成，在“影像”中打开，试着切到另一个分段播放。

**完成标准：手机收到实际录像，并能播放与切换分段。** “发现了手机”或“已经配对”本身不证明录像已经传送成功。

后续在同网并开启接收时可重连；地址变化则使用手机当前显示的地址。六位码过期不影响已经保存的配对。传完可以停止接收，已收到的录像仍可离线播放。

从 V4 升级时，两端更新后重新安全配对一次。无需卸载来解除旧配对，也不要退回旧明文连接。手机的录像接收入口不提供远程开始车机录像或远程实时预览。

## 4. 旧用户升级、换手机

| 情况 | 怎么做 |
| --- | --- |
| 已装本项目车机版或原 OpenAVM 手机版 | 使用同签名的新包覆盖安装，不清数据 |
| 装的是早期“本车能力检查／独立助手” | 它和正常手机版包名不同；先联系作者确认迁移方式，不通过卸载强行解决 |
| 安装提示签名不同或不允许升级 | 保留现有 App 与数据，反馈旧版本和新包文件名 |
| 换到新手机 | 重新登录、设家和偏好、添加卡片；需要录像时重新配对 |
| 两台手机都保留 OpenAVM | 先暂停旧手机的预约、离家守护和到家关闭，再启用新手机，避免重复执行 |

覆盖升级保留同一安装中的数据，不等于跨手机自动迁移。安装包不会带来旧手机的账号、位置、卡片和已接收录像；重要录像单独备份。

## 5. 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 刷新成功，温度或状态时间没变 | 可能仍是车辆上次回传。看数据时间；需要测温时使用温度旁按钮 |
| 哨兵没有立刻开启或关闭 | 看规则、家范围、数据新旧、后台权限及操作记录；到家需两次确认 |
| 尾门没有抬起 | 按“尾门解锁”理解，必要时到车尾按实体按钮；不承诺电动抬起或关闭 |
| 回车只有 Logo | 这是 Logo 模式；点它恢复预览，或改成完整悬浮窗 |
| 回车短暂黑屏／等待预览 | 等相机就绪；仍无画面时检查权限、原车相机占用及应用运行状态 |
| 手机找不到车机／收不到录像 | 两端同网、手机接收已开启、V5 配套版本、完整安全配对；热点不应隔离设备 |
| 旧视频直接跳段出错 | 记录具体错误、视频来源与两端版本；保留原片，勿先删除重传 |
| USB 已插入但录像写到车机 | 看实际存储位置，确认 USB 已识别且可写 |

正常分段连续不等于所有中断场景都无丢失。历史休眠测试中有一次录像写入异常仍待定位；回车恢复的修复不代表该异常已解决。遇到录像中断，保存时间、模式和存储目标等信息反馈；重要用途请检查录像结果。

应用内也有新手帮助：手机“更多 → 新手指南”；车机首页或设置中的“新手教程与帮助”。

需要反馈时，附上两端版本、车型／固件、操作顺序和提示文字。公开截图遮住位置、车牌、账号与配对信息，私人录像不要直接放进公开 Issue。
