## Deliberate limits

The approved deferred scope remains deferred: synchronized time-lapse, downloadable map packs, navigation/road snapping, accident classification, composited three-camera export, HUD burned into pixels, transcoding and cloud route history. No required normal-recording feature is replaced by a probe.

An observed clock anchor is not a calibrated camera exposure timestamp. The final frame's extent may be estimated from observed cadence. A GPS route cannot be recovered when no location observations were captured. Pedal values cannot be displayed as percentages until the actual firmware's range and units are established.

Both APKs, the bilingual guide and one comprehensive checklist are delivered together. The owner can perform one integrated test and return the combined JSON afterward.
