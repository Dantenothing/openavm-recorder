## 我应该装哪个？

| 你想做什么 | 安装哪个 | 安装位置 |
| --- | --- | --- |
| 录像、回看、使用悬浮后视镜 | **OpenAVM Recorder**，文件名以 `OpenAVM-Recorder-` 开头 | 车机 |
| 查看车况、备车、停车守护、桌面卡片 | **OpenAVM 手机版**，文件名以 `OpenAVM-Phone-` 开头 | Android 手机 |
| 把车机录像传到手机播放或分享 | 两个都装，再配对一次 | 车机和手机 |

在发布页选择 **V5** 对应的附件，不要把车机 APK 装到手机，也不要把历史 V4 手机版当作 V5 配套包。

**手机不是车机录像的必需品，手机车控也不依赖车机安装 Recorder。** 不需要搭建私人服务器：手机车控连接极氪云端，车机录像通过同一 Wi-Fi 或手机热点传输。

## 车机版：记录、回看与悬浮预览

- **环视录像**：普通与延时模式；兼容配置下，正常切换录像分段时保持采集连续。车内与红外相机是否可用取决于车辆固件。
- **悬浮后视镜**：不录像也能预览，支持前后左右、四宫格、车内画面、窗口移动与缩放。
- **回车恢复**：选择保留 Logo 入口、恢复完整预览，或明确开启后在回车时自动开始录像。每次安装或更新后会重新确认选择。
- **录像管理**：按日期查找，同次录像按分段归组；保存紧急视频，保护重要片段。
- **手机传输与音效工具**：把已有录像传到手机，也可从本地音频或视频制作车辆音效 WAV 文件。

保留悬浮窗入口不等于离车后持续录像。回车恢复需要应用仍在运行；车机重启或应用被系统结束后，请重新打开。

## 手机版：把常用操作放到手边

- **看车况**：车内温度、电量、续航、位置与车辆状态，配合数据时间判断新旧。
- **智能备车**：设置目标温度、最长时长与座椅偏好；点击开始，再次点击停止。也可安排预约出发。
- **原厂哨兵自动化**：开启规则后，在确认离家停车时打开原厂哨兵；可另行开启“确认到家后自动关闭”。在本应用手动关闭后，当次停车暂停自动开启。
- **四种桌面卡片**：2×2、4×1、4×2、4×3。常用操作可直接在卡片发起，进度显示在卡片中，也有明确的应用入口。
- **空调与座椅**：使用账号和车辆支持的温度、座椅通风及加热控制。
- **录像与个性化**：接收、播放、导出与分享录像；设置车辆昵称、外观与车牌样式。

**普通刷新只读取车况。** 温度旁的独立刷新用于更新车温，必要时会短暂开启空调，再请求结束本次临时空调；界面会显示进度。刷新成功不代表车辆刚刚重新测温，请一起查看数据时间。

手机自动化控制的是车辆原有哨兵功能。它与车机 Recorder 的录像是两套功能，也不提供手机远程启动 Recorder 录像或远程实时看摄像头。

## 兼容与首次使用

| 项目 | 当前范围 |
| --- | --- |
| 车机 | Android 8.0+、ARM64，且固件允许安装应用并提供兼容的 App Lab 摄像头与存储访问 |
| 手机 | Android 8.0+；本版不提供 iOS 应用 |
| 手机云端车控 | 以澳洲版极氪 7X / AU 1.6.6 适配为当前基线；其他地区、车型与固件未作通用兼容承诺 |
| 车辆账号 | 需要已有车辆授权；guest 共享账号的功能以主账号授予的权限为限 |
| 界面语言 | 车机：英语、简体中文、繁体中文、泰语、越南语、阿拉伯语；手机：简体中文、英语 |

5.0.1 手机候选版不内置或自动下载厂商连接参数。云端功能需要用户自行导入配置，本地影像无需配置即可使用。登录后选择车辆，再按需要设置家的位置、备车偏好、桌面卡片和自动化。

两端使用配套 V5 版本传输录像。首次安全配对需要核对完整指纹；从旧 V4 连接迁移时重新配对一次。已收到的录像可以离线播放。

## 升级与使用边界

- **覆盖安装，不要先卸载。** 请使用本项目提供且与旧版签名一致的安装包；早期独立助手用户见使用指南。
- 车机首次进入 V5 会应用一次默认方向配置：右侧驾驶位，前 1／后 2／左 3／右 4，车内 1／红外 0。请停车核对，之后的手动修改会保留。
- 录像前查看实际存储目标，等待保存完成再拔 USB。重要录像另做备份。
- 手机省电限制、网络及车辆休眠可能延迟车况与自动化；桌面卡片不承诺持续实时。
- 车机相机、供电及存储异常可能中断录像。本版不承诺停车持续录像或系统结束应用后的自动恢复。

详细操作和常见问题见[使用指南](docs/v5/GETTING_STARTED.zh-CN.md)。

## 数据与权限

登录会话和配对凭据加密保存在手机本机；安装包不包含使用者的账号、车辆或家的位置。车控需要访问极氪云端，地址匹配使用手机系统的地址服务；这不代表所有数据都只在本地处理。

录像默认保存在所选车机存储或接收它的手机中。两端配对后的录像传输使用加密局域网连接，不依赖 OpenAVM 私人服务器。仅查看已接收录像不需要登录极氪账号。

按使用的功能授予相机、存储、悬浮显示、通知或后台运行等权限。请停车后完成车机设置。
