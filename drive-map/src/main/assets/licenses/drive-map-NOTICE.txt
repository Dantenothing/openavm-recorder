The public map service is optional. The app requests tiles only while the
user has selected street maps in a visible, foreground playback panel.
Requested tiles reveal the viewed area to the provider. Recorded route
data is supplied directly to the local renderer, never uploaded as a
route file. The local trace view needs no map provider or network.
